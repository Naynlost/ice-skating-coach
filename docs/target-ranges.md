# Hedef araliklar

Gorev 0.4. Antrenorle otur, her metrik icin seviye bazli hedef aralik yaz.
Bilmedigi yerde "bilmiyorum" yazsin, uydurmasin. Bos hucre "bu metrik bu
seviyede degerlendirilmiyor" demektir.

Gorev 2.2'de bu tablo `elements/jump/rules.yaml` icine gecirilir.

| Metrik | Birim | Yon | beginner | intermediate | advanced |
|---|---|---|---|---|---|
| loading_knee_angle_min | derece | dusuk iyi | | | |
| takeoff_torso_lean | derece | dusuk iyi | | | |
| airtime | saniye | yuksek iyi | | | |
| jump_height | metre | yuksek iyi | | | |
| arm_pullin_delay | saniye | dusuk iyi | | | |
| landing_knee_angle | derece | dusuk iyi | | | |
| checkout_free_leg_angle | derece | yuksek iyi | | | |
